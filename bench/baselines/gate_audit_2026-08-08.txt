CORRECTION -- THIS TABLE SUPERSEDES THE FIRST RUN OF THIS AUDIT
================================================================================
The first run used ONE shared `--refs 3` BASE for all five gates and reported
`sub8_grain` as dead weight (+0.04 / -0.11%) and `mbtree_grain` as inert
(byte-identical). BOTH WERE WRONG, and the cause was the harness, not the gates.

`sub8_grain` guards a split arm behind:

    want_split = (sub8x8_split_on() || cfg.tune_sub8x8_split) && num_refs == 1

At `--refs 3` that arm is alive only on the FIRST P frame of each GOP, so the audit
measured a gate that was switched off and read the residue as a verdict. The census
had it right all along: it ran `EncoderConfig::new()` (num_ref_frames = 1) and
counted 11484 macroblocks = 29 of 30 frames -- the gate firing on essentially the
whole clip.

Re-run at the shipped default:

  gate             clip           BD(gate off vs shipped)   verdict
  aq_grain_veto    grain_akiyo              +36.12%         strongly justified
  aq_grain_veto    grain_flat                +0.23%         justified
  sub8_grain       grain_akiyo               +0.08%         justified (small)
  sub8_grain       grain_flat                +0.16%         justified (small)
  mbtree_grain     grain_akiyo               +4.18%         justified
  mbtree_grain     grain_flat            byte-identical     does not act here
  mbtree_backoff   --                       REFUSED         never fires
  mbtree_spread    harbour/foreman/mobile  latch-on is
                                     +0.78/+1.00/+0.22%     DISABLING was correct

So FOUR of the five earn their keep, one is untestable on this corpus, and NONE is
dead weight. The earlier "two inert gates" finding was an artifact.

The mbtree_spread ship decision SURVIVES the correction, and now has independent
confirmation at the default configuration: re-enabling the latch (SDMIN=1.111)
costs +0.78% (harbour), +1.00% (foreman), +0.22% (mobile). The original sweep at
refs 3 said the same thing with the opposite sign convention (-0.88 / -1.20 to
disable). Two configurations, same direction.

WHAT THIS COST AND WHAT FIXED IT
The harness now forbids a shared reference count: `BASE` carries no `--refs`, and
each gate declares its own configuration next to its acting clips. A gate is only
measurable in a configuration where it can run, which is R5 ("the census must match
the quality configuration") pointed at the tool instead of the operator.
